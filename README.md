# ШУМ · Северо-Запад

Сайт-презентация кейса №6 «Конструктор сообществ»: аналитика 68 анкет и концепция развития сообщества Центра «ШУМ».

Не набор слайдов, а один длинный скролл: паспорт проекта → данные → сегменты → модель → план → метрики → цитаты → итог.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка типов + сборка в dist/
npm run preview  # локальный просмотр сборки
```

## Как это устроено

- **React 19 + TypeScript + Vite.** Никаких UI-библиотек: только собственный CSS.
- **Один экран — одна глава.** 15 глав плюс паспорт проекта. Нижняя лента глав фиксирована, текущая глава подсвечивается красной риской.
- **Навигация:** `+ МЕНЮ` — оглавление, `←` / `→` — предыдущая / следующая глава, `Home` — в начало, `End` — в итог.
- **Печать:** `Cmd/Ctrl + P` собирает сайт в PDF-деку — каждая глава начинается с новой страницы, тёмная тема инвертируется в светлую для читаемости.

## Дизайн-система

Строго по Freshman: чистый чёрный `#000000`, белый `#ffffff`, графит `#101010`, сигнальный красный `#ff2936` точечно. Ноль скруглений, никаких теней и градиентов. Крупный сверхтонкий курсивный серифный логотип, сжатые uppercase-метки, рукописные подписи в скобках.

Шрифты — свободные аналоги с кириллицей: Cormorant Garamond, Inter, Oswald, Caveat.

## Данные

Источник — мастер-документ кейса: 68 анкет, 51 полная, 61 с ролью, 35 интервью, 45 приглашений; пять сегментов; расшифровки столов и брифинг Центра.

Модель управления, конституция, роли и KPI — **проектное предложение**, а не действующие правила Центра. Именные цитаты требуют сверки со звуком и согласования с авторами.

Поле «Команда» в паспорте проекта — заглушка «Северо-Запад»: название и состав нужно подставить перед сдачей материалов.
